# Интерактивный макет Windows-приложения

Файл **UI_PROTOTYPE.html** — автономный интерактивный прототип дизайна. Для просмотра откройте его в браузере на компьютере: это только демонстрация, будущая программа будет нативной Windows (PySide6). В макете нет сервера, реальной 1С, SQL Server и RFID.

## Как проверить
1. Откройте UI_PROTOTYPE.html двойным щелчком.
2. На экране «Поиск и операции» нажмите «Пример: чужая полка»: образец S-000124 числится на A-02-03, а выбрано B-01-02. Проверьте кнопку «Переместить сюда» без второго сканирования.
3. Нажмите «Пример: два образца»: товарный ШК 4601234567890 должен показать два физических образца, не выбирать первый автоматически.
4. Нажмите «Удалить образец» и проверьте подтверждение. История должна остаться.
5. Перейдите в «Создать образец»: создайте ещё один экземпляр того же товара и убедитесь, что код новый.
6. Перейдите в «Проверка места»: начните проверку, сканируйте S-000125 или EPC, посмотрите списки найденных/чужих/не найденных. Отсутствие при проверке не удаляет образец.
7. Посмотрите «История» и «Настройки».

- Какие кнопки и поля лишние?
- Достаточно ли информации на карточке образца?
- Нужно ли сканировать место перед каждой операцией?
- Нужно ли печатать этикетку сразу после создания?
- Каким должен быть экран C5? Здесь пока показан только Windows интерфейс.
- Кто вправе удалять образец?

## Ограничения
Все данные вымышлены и сбрасываются при обновлении страницы. Реальная программа не будет HTML-страницей: прототип служит для согласования интерфейса и сценариев, а не для проверки аппаратной интеграции.
