# Запрос на изменение дизайна для Codex

## Причина
Пользователь отверг первоначальный UI_PROTOTYPE.html: одиночная карточка занимает слишком много места и не позволяет эффективно сканировать 100 товаров для создания образцов или исправлять 50 образцов за одну операцию.

## Обязательное изменение
1. Основной экран заменить на **Рабочий список образцов**: компактная таблица с массовым выбором, фильтрами по полке/факту обнаружения/остатку 1С, явной целевой полкой и массовыми MOVE/DELETE.
2. Экран создания заменить на **Создать партией**: выбрать полку, сканировать 100 товарных ШК подряд, просмотреть очередь, создать все N образцов одной подтверждённой командой.
3. Разделить workingLocationId, accountedLocationId, observedLocationId, targetLocationId.
4. Добавить серверные пакетные endpoints и атомарные транзакции из BULK_API_CONTRACTS.md.
5. Использовать UI_PROTOTYPE_V2.html как приоритетный визуальный прототип; старый UI_PROTOTYPE.html считать устаревшим.
6. Выполнить новые приёмочные сценарии из BULK_UX_SPEC.md до объявления готовности.

## Приоритет документов
Этот файл + BULK_UX_SPEC.md + BULK_API_CONTRACTS.md имеют приоритет над противоречащими им UX_FLOWS.md, PRODUCT_SPEC.md и API_CONTRACTS.md по вопросам массовой работы. Базовые правила безопасности, аудита, 1С read-only, идемпотентности и tombstones остаются обязательными.

## Согласование
Прототип v2 — предложение, а не окончательно утверждённый пользователем дизайн. Не считать его утверждённым до проверки пользователем.
