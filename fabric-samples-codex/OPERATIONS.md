# Установка и эксплуатация

## Windows
Backend устанавливается как Windows Service под отдельной учётной записью. Desktop — обычный exe и ярлык. API слушает только согласованный LAN-интерфейс. Перед изменением Windows Firewall, созданием службы и SQL БД запросить разрешение.

## Секреты
Пароль 1С, строка SQL и токены устройств хранятся в защищённой конфигурации/Windows Credential Manager либо с ограниченными ACL; не в Git и не в логах. Отдельные read-only учётные данные 1С.

## База
FabricSamples — отдельная БД SQL Server. Миграции Alembic применяются отдельно, с предварительным backup. SQL логин приложения не имеет доступа к 1С БД.

## HTTPS и C5
Для C5 использовать сертификат, доверенный Android-клиентом. Не отключать проверку сертификатов ради теста. Проверить стабильный IP/имя хоста и Wi-Fi.

## Backup
Периодические SQL Server backup, хранение копии на отдельном носителе/сервере, политика ротации, контроль ошибок. Регулярно тестировать RESTORE в отдельную тестовую БД. Секреты и конфигурация тоже должны иметь защищённую копию.

## Обновление
Остановить операции, создать backup, применить миграции, обновить сервис/UI, smoke tests, вернуть в эксплуатацию. Для отката иметь предыдущие установочные файлы и проверенный план восстановления БД. Не откатывать схему вслепую при новых данных.

## Мониторинг
Логи: запросы, ошибки, изменения, sync 1С, C5 reconnect, конфликты. Состояние службы, дата последней синхронизации 1С, свободное место SQL, успешность backup.

## Миграция старой системы
Если в 1С уже есть данные УОТ_ОбразцыТканей/места/EPC: сделать read-only аудит, выгрузить в тестовую БД, сверить количества и ключи. Рабочие данные 1С не удалять.

## Права
Operator — поиск, проверки, создание/перемещение; право удаления — по утверждённой политике. Admin — управление местами, устройствами, аудитом, настройками. Все изменения авторизованы сервером.
