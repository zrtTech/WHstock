# Прототип v9 — уточнение

Товарный ШК общий для рулона и образца. Сканирование товарного ШК создаёт отдельный физический образец, привязанный к артикулу. Внутренний ID не печатается. EPC уникален для каждого физического экземпляра и связывается после фактического чтения RFID-метки. Работа оператора — по артикулам. Нет обязательной печати этикеток.
