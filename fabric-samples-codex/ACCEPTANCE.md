# Приёмка

Система считается полностью готовой только при PASS по каждому обязательному пункту:

- [ ] Нативная Windows программа запускается с ярлыка, не требует браузера.
- [ ] Windows Service и API работают после перезагрузки.
- [ ] 1С читается через подтверждённый read-only интерфейс; в 1С ничего не записывается.
- [ ] Поиск по артикулу, имени, товарному ШК, sampleCode и EPC.
- [ ] 1/2/N экземпляров одного товара различаются.
- [ ] Создание, перемещение и окончательное удаление физического образца.
- [ ] При чужом месте есть «Переместить сюда» без повторного сканирования.
- [ ] Проверка места не делает автоматических MOVE/DELETE.
- [ ] Отсутствующий при проверке образец не удаляется.
- [ ] RFID EPC не назначается двум активным образцам.
- [ ] Повторы requestId не создают дубли.
- [ ] Конкурирующие операции не теряют данные.
- [ ] USB-сканер проверен физически.
- [ ] Chainway C5 проверен физически с RFID и 2D.
- [ ] Офлайн-очередь C5 и reconnect проверены физически.
- [ ] Закрытие Windows GUI не останавливает API.
- [ ] Логи ошибок доступны без секретов.
- [ ] Backup создан, восстановлен в тестовую БД и проверен.
- [ ] Установка и обновление документированы.
- [ ] Нет заглушек вместо работающих интеграций.
- [ ] Тесты pytest/интеграционные проходят на целевой среде.

Для каждого пункта Codex прикладывает evidence и статус PASS/FAIL/NOT_TESTED. Необследованное оборудование = NOT_TESTED, не PASS.


## Обязательные новые критерии массовой работы

- [ ] 100 последовательных товарных сканов без подтверждения каждого.
- [ ] 100 образцов создаются одной командой на выбранной полке, каждый с уникальным sampleCode.
- [ ] Повторный скан того же товара увеличивает количество, виден и исправляем до сохранения.
- [ ] Неизвестный/неоднозначный код блокирует пакет до исправления.
- [ ] Повтор batchRequestId не создаёт дублей.
- [ ] 50 чужих образцов отображаются в компактной таблице с учётной и фактической полками.
- [ ] Выделить все 50 по фильтру, предпросмотр, массовое перемещение без повторного сканирования.
- [ ] Массовое удаление только выбранных и после подтверждения; нулевой остаток 1С не удаляет автоматически.
- [ ] Различаются рабочая полка, учётная полка, место обнаружения и целевая полка.
- [ ] При конфликте версии одного образца атомарный пакет не применяет остальные строки молча.

Подробные тесты и макет: BULK_UX_SPEC.md и UI_PROTOTYPE_V2.html.
