# Сценарии интерфейса Windows и C5

## Главное окно Windows
Сверху: режим [Поиск / Создание / Проверка места], выбранное место, поле «Сканируйте код», индикатор связи. В центре: карточка найденного образца или товара; ниже: большие контекстные действия. Никакого браузера и длинного дерева документов.

## Режим «Поиск/операция»
1. HID-сканер вводит код как клавиатура и завершает Enter; приложение распознаёт завершение.
2. Backend возвращает тип совпадения: UNIQUE_SAMPLE, PRODUCT_ONLY, MULTIPLE_SAMPLES, UNKNOWN, DELETED.
3. UNIQUE_SAMPLE: на экране код образца, товар, текущее место, обнаруженное/выбранное место, кнопки «Переместить сюда», «Другое место», «Удалить».
4. PRODUCT_ONLY/MULTIPLE_SAMPLES: список экземпляров с местами; оператор выбирает один. Запрещено изменять первый автоматически.
5. UNKNOWN: понятная ошибка и возможность повторного сканирования.
6. После операции экран подтверждает результат; сканирование следующего кода доступно сразу.

## Выбранная стойка
Оператор может заранее выбрать стойку сканированием кода места или через поиск. Это КОНТЕКСТ наблюдения. Выбор стойки не перемещает образцы. Для найденного образца из другой стойки кнопка «Переместить сюда» должна быть доступна сразу.

## Создание
Сканировать товарный ШК → показать товар → выбрать стойку → «Создать образец» → получить уникальный код → при наличии принтера распечатать этикетку → при необходимости привязать RFID. Если один товар имеет несколько ШК, все ведут к одному товару через каталог 1С.

## Удаление
Показывать конкретный sampleCode, товар и место. Кнопка «Удалить» → подтверждение «Удалить образец [код]? Восстановления нет» → операция. Не удалять по одному лишь товарному ШК, если есть неоднозначность.

## Проверка места
Сканировать место → «Начать проверку» → сервер сохраняет snapshot ожидаемых sampleId → сканировать образцы/EPC → помечать найденные, чужие, неизвестные, повторные → «Завершить» → показать найденные/не найденные/чужие. Из списка чужих можно открыть карточку и нажать «Переместить сюда» без повторного сканирования. Завершение проверки не меняет состояние образцов.

## Клавиатура и фокус
- Поле сканирования не должно терять ввод из-за случайного переключения фокуса.
- Для USB HID сканера поддержать суффикс Enter/Tab; для USB-COM реализовать отдельный драйверный адаптер только при необходимости.
- Не смешивать ручной ввод с быстрым потоком сканера; ввод можно завершать Enter.
- Ошибки — коротко, с возможностью повторить без перезапуска.

## C5
Сканирование UHF может давать серию EPC: дедупликация в рамках одной сессии чтения, сохранение сырых фактов и отправка наблюдений. Операции требуют явного действия пользователя. При офлайне операции помещаются в постоянную очередь и повторяются с тем же requestId. Не объявлять серверный успех до подтверждения сервера.
